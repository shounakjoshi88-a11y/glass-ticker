# Scoop bucket for Glass Ticker

A [Scoop](https://scoop.sh) bucket that installs
[Glass Ticker](https://github.com/shounakjoshi88-a11y/glass-ticker) - a
frameless, acrylic-glass desktop market ticker for Windows.

## Install

```powershell
scoop bucket add glass-ticker https://github.com/shounakjoshi88-a11y/scoop-bucket
scoop install glass-ticker
```

## Update

```powershell
scoop update
scoop update glass-ticker
```

The manifest tracks the published releases, so `scoop update` picks up new
versions automatically.
